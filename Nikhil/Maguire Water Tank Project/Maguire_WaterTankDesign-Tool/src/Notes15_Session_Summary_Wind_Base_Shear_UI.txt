### 3. GOVERNING LOADS RESOLUTION IN LOADSERVICE
- **Shear Demand Logic (`LoadService.cs`)**:
  * Previously, `LoadService.GetGoverningLoads()` compared raw unreduced seismic base shear ($V_{\text{seismic}} = 52.29\text{ kips}$) against wind shear ($V_{\text{wind}} = 34.32\text{ kips}$), which resulted in selecting seismic and producing $52.29 \times 1.667 = 87.16\text{ kips}$.
  * In ASD combinations, seismic is factored by 0.6 ($0.6 \times 52.29 = 31.37\text{ kips}$, giving $31.37 \times 1.667 = 52.30\text{ kips}$).
  * Per user explicit requirement: For `TankType.MultiColumn`, Shear Demand ($V_u$) **always** uses Wind Shear:
    $$V_u = V_{\text{wind}} \times 1.667$$
  * For user's live project with $V_{\text{wind}} = 34.32\text{ kips}$:
    $$V_u = 34.32 \times 1.667 = \mathbf{57.2114\text{ kips}}$$
  * Single-Leg maintains `Vu = Math.Max(windV, seismicV)`.

### 4. CROSS-MODULE DISTRIBUTION OF PU, MU, AND VU
| Module | Factored Axial $P_u$ | Overturning Moment $M_u$ | Shear Demand $V_u$ |
| :--- | :---: | :---: | :---: |
| **Anchor Bolt** | Used (Gravity & Comp) | Used (Tension Demand $T_u$) | Used (Bolt Shear $V_b$) |
| **Base Plate** | Used (Bearing $f_p$, Thickness $t_{\text{req}}$) | Used (Pedestal Moment $M_{u,\text{ped}}$, Eccentricity $e$) | Not Used (AISC plate design governed by bearing & flexure) |
| **Pedestal** | Used ($P_{\text{grav}} = P_u / N$, Max $P_{\text{comp}}$) | Used ($T_{\text{leg}}$ uplift, P-M interaction) | Used ($V_{u,\text{ped}} = V_u / N$, Tie Spacing $s_{\max}$) |
| **Footing** | Used ($P_{\text{leg}} = P_u / N$, Max $P_{\text{comp}}$) | Used ($T_{\text{leg}}$ uplift, Soil Bearing $q$, Flexure) | Used (Sliding Check $\text{FS} = \frac{\mu P_{\text{comp}}}{V_{\text{leg}}}$) |
