### 1. OVERVIEW & CODE UPDATES COMPLETED
1. **Multi-Column Governing Loads (`LoadService.cs`)**:
   - **Factored Axial Load ($P_u$)**:
     $$P_u = \left(\text{Tank Water Weight} + \text{Tank Steel Weight} + \text{All Column Segments} + \text{Riser Segments} + \text{Struts/Bracing} + \text{Misc}\right) \times 1.667$$
   - **Factored Overturning Moment ($M_u$)**:
     $$M_u = \max\left(0.6 \times M_{\text{wind}}, \; 0.6 \times M_{\text{seismic}}\right) \times 1.667$$
     *(Matches Row 5 `D + 0.6(W or E)` of the Load Combinations table $\times 1.667$. In 100K and 400K, Seismic governs; in 500K with `173 mph` wind, Wind governs.)*
   - **Factored Shear Demand ($V_u$)**:
     $$V_u = V_{\text{wind}} \times 1.667$$
   - Single-Column (`TankType.SingleColumn`) logic remains 100% untouched.

2. **Automatic Per-Project Column Count (`NoOfColumns`) (`AppState.cs` & `WaterTankDbContext.cs`)**:
   - `appstate.json` is saved and loaded per project folder alongside `project_data.db`.
   - Switching between 100K (`4` legs) and 400K/500K (`6` legs) automatically updates `AppState.NoOfColumns`.

3. **Anchor Bolt UI (`AnchorBoltParameters.cs` & `AnchorBoltProperties.cs`)**:
   - Added read-only `Number of Legs (Columns)` field on both Input and Results screens.
   - Shortened `Axial Load (Pu) (kips)` label and called `txtPu.BringToFront()` so 7-digit numbers (`7533.555`) are never clipped.

### 4. SUMMARY OF PDF DISCREPANCIES & FORMULA TYPOS (100K, 400K, 500K)
1. **Step 8 ($\phi V_s = 24.3\text{ kips}$ vs Software's $28.67\text{ kips}$)**:
   - All 3 PDFs multiplied by bolt diameter $d_b = 1.50\text{ in}$ ($0.75 \times 0.6 \times 36 \times 1.50 = 24.3\text{ kips}$) instead of bolt net tensile area $A_b = 1.77\text{ in}^2$ ($28.67\text{ kips}$).
2. **Step 11 ($V_{cp} = 576\text{ kips}$ vs Software's $471.44\text{ kips}$)**:
   - All 3 PDFs left $V_{cp} = 576\text{ kips}$ from an old $h_{ef} = 40\text{ in}$ sheet instead of $2.0 \times 235.72 = 471.44\text{ kips}$ for $h_{ef} = 35\text{ in}$.
3. **Step 12 (Interaction Check)**:
   - All 3 PDFs divided $T_{\text{leg}}$ by $3$ instead of $4$ bolts per leg (`103.65/3 = 34.55`, `38.231/3 = 12.747`, `122/3 = 40.654`) instead of using $T_{\text{bolt}}$ from Step 5 (`25.91`, `9.558`, `30.48`).
4. **Load Input Mix-Ups on Page 1 of the PDFs**:
   - **100K PDF**: Used `100K-DE` loads with 250K $D_{cl} = 41.05\text{ ft}$.
   - **400K PDF**: Used 400K geometry ($D_{cl} = 50\text{ ft}$, $N = 6$) with `300K-TORO` loads ($P_u = 4623.218$, $M_u = 3823.08$, $V_u = 62.4134$).
   - **500K PDF**: Used `500K-TORO` $P_u$ (`7550.979`) and `173 mph` Wind $M_u$ (`13656.1295`), but used Seismic Shear (`115.783 kips`) for $V_u$ instead of `173 mph` Wind Shear (`229.1061 kips`).
